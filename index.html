# Daily Duel Jeden Tag fünf Challenges — für alle Spieler dieselben. Punkte gibt es nach Tempo, dazu Streaks, Coins, Duelle gegen Freunde und ein paar Spezialmodi. Prototyp als Web-App. Läuft ohne Server, ohne Build-Schritt, ohne Abhängigkeiten. ## Ausprobieren `index.html` im Browser öffnen. Das war's. Für die Handy-Ansicht: Entwicklertools öffnen (F12) und die Geräte-Ansicht einschalten. ## Auf GitHub veröffentlichen 1. Neues Repository anlegen, zum Beispiel `daily-duel`. 2. Die vier Dateien hochladen: `index.html`, `style.css`, `game.js`, `README.md`. 3. Im Repository auf **Settings → Pages** gehen. 4. Unter **Source** den Branch `main` und den Ordner `/ (root)` wählen, dann **Save**. 5. Nach ein bis zwei Minuten liegt die App unter `https://DEINNAME.github.io/daily-duel/`. Per Kommandozeile: ```bash git init git add . git commit -m "Daily Duel: erster Prototyp" git branch -M main git remote add origin https://github.com/DEINNAME/daily-duel.git git push -u origin main ``` ## Aufbau | Datei | Inhalt | | --- | --- | | `index.html` | Struktur aller Screens: Home, Duelle, Modi, Rangliste, Profil, Shop, Spiel, Ergebnis | | `style.css` | Farben als CSS-Variablen ganz oben, darunter die Bausteine nach Bereichen sortiert | | `game.js` | Spiellogik: Challenges, Punkte, Streaks, Coins, Duelle, Ranglisten | ## Wie das Spiel funktioniert **Gleiche Challenges für alle.** Aus dem Datum wird ein Startwert berechnet, aus dem ein Zufallsgenerator die fünf Challenges des Tages erzeugt. Gleicher Tag heißt gleicher Startwert heißt gleiche Aufgaben — ganz ohne Server. Zu finden in `dailySet()` und `build()`. **Punkte.** Richtig beantwortet gibt zwischen 200 und 1.000 Punkte, je nachdem, wie viel Zeitlimit übrig war. Falsch gibt null. Siehe `scoreOf()`. **Challenge-Arten.** Memory, Reaction, Math, Color, Words und Observation. Jede Art hat in `build()` ihre Erzeugung und in `play()` ihre Darstellung. **Spielstand.** Liegt im Browserspeicher unter dem Schlüssel `dd_v2`. Zum Zurücksetzen in der Konsole `localStorage.removeItem('dd_v2')` eingeben und neu laden. ## Was hier nur simuliert ist Der Prototyp läuft ohne Backend. Deshalb sind folgende Dinge nachgestellt: - **Freunde und Duelle** — die Gegner sind Bots mit festen Stärkewerten - **Ranglisten** — erfunden, aber pro Tag stabil - **Team Duel** — Mitspieler und Gegner werden berechnet, nicht gespielt - **Tagesreset** — richtet sich nach der Uhr des Geräts, nicht nach einem Server Für eine echte App braucht es Accounts, eine Datenbank und serverseitige Punkteprüfung. ## Selbst anpassen - **Farben** — die Variablen am Anfang von `style.css` (`--accent`, `--gold`, `--text`) - **Neue Challenge-Art** — in `TYPES` eintragen, in `build()` erzeugen, in `play()` darstellen - **Schwierigkeit** — die `limit`-Werte in `build()` sind die Zeitlimits in Millisekunden - **Shop-Inhalte** — das Objekt `SHOP` in `game.js` /* Grundlage: Vollbild auf dem Handy, Ränder für Notch und Home-Leiste */ :root{ color-scheme: light;
